# 교안 정리 파이프라인과 교차 리뷰 게이트

AI가 만든 과목별 학습 가이드를 **다른 계열 모델이 리뷰**하고, 통과 여부는 **코드(게이트)가 판정**하게 만든 개인 작업 도구다. 2026년 8월부터 SKALA 교육과정 과목 정리에 써 왔다.

- `gate.py` — 작업 계약(`contract.md`)과 리뷰(`review.md`), 쪽 커버리지 처분표를 검사해 exit code로 통과·막힘을 낸다. 표준 라이브러리만 쓴다
- `test_gate.py` — 리뷰에서 찾은 구멍을 옮긴 회귀 테스트. `python3 test_gate.py`
- `AGENT_WORKFLOW.md` — 위험도 5문항, 워크로드별 절차, 게이트 사용법을 적은 정본
- `metrics.tsv` — 작업마다 남긴 리뷰 기록(유효 지적 · 오지적 · 게이트 회귀)

## 무엇을 검사하고 무엇을 검사하지 않나

게이트는 리뷰가 있는지, 지적의 형식, 작업 ID와 위험 플래그의 일치, 교안 쪽 커버리지를 검사한다. 내용이 맞는지는 판정하지 않는다. 그건 리뷰어와 사람이 확인한다.

## 넣지 않은 것

과목 교안과 정리 결과물, 작업별 계약·리뷰 파일(`handoff/`)은 강의 자료 내용이 섞여 있어 이 저장소에 두지 않는다. 문서 안의 `~/skala-workspace/...` 경로는 원래 작업 폴더 구조를 가리킨다.
